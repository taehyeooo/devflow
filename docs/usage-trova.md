### 실사용에서 찾은 플러그인 버그 3개
1. 배포 후 확인이 "0건" 결과(`grep -c` 종료 코드 1)에서 스크립트 전체가 멈춤 → `|| true`, 확인 명령 입력 분리(0.1.1)
2. 앱 폴더로 cd한 뒤 설정을 다시 찾아 다른 레포 설정을 읽음 → 처음 찾은 설정 고정(0.1.2)
3. 원복 메시지에 남은 패치 수가 두 번 찍힘 → 출력 정리(0.1.3)

손으로 하던 절차를 그대로 옮겨도, 실제로 한 번 돌려 봐야 드러나는 문제가 있었다 — 그래서 첫 사용 기록을 남긴다.
