# 시뮬레이터 QA (devflow)

스크립트: `bash "${CLAUDE_PLUGIN_ROOT}/scripts/qa-sim.sh" <명령>`

## 순서
1. **사용량 확인**: 외부 AI API를 쓰는 흐름이면 먼저 `quota` — 하루 한도를 운영과 같이 쓰는 키라면 남은 양을 사용자에게 알린다.
2. **데이터 기준 저장**: `snapshot save` (테스트 계정의 작업·장소·여행 등 개수)
3. **준비**: `start` — 임시 QA 토큰 패치, 로컬 서버를 보는 Metro, 앱 재실행. 창이 여러 개면 `front`로 QA 기기를 앞으로.
4. **진행**: `tap X Y 이름`(누르고 캡처) → 캡처를 읽어 확인 → 다음 탭. 화면이 바뀌는 탭 전에는 먼저 `shot`으로 위치를 확인한다.
   - 좌표는 pt(캡처 px ÷ 화면 배율). 큰 글자 확인은 `text accessibility-extra-extra-extra-large`, 끝나면 `text large`.
5. **정리**(stop이 QA 한 번에 걸린 시간·탭 수를 기록한다): 만든 테스트 데이터를 지운 뒤 `snapshot check`(QA 전과 같아야 함) → `stop`(남은 패치 0건이어야 함).
6. 결과를 사용자에게: 실행 환경(로컬/운영)을 꼭 밝히고, 캡처로 확인한 것과 확인하지 못한 것을 나눠 말한다.

## 지킬 것
- 임시 토큰 패치는 커밋하지 않는다(commit-guard 훅이 막는다).
- 사용자 실제 계정 기기는 건드리지 않고, 설정의 QA 전용 기기만 쓴다.
